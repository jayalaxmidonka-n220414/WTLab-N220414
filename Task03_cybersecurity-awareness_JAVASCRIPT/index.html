CYBERSECURITY AWARENESS

Cybersecurity awareness involves educating individuals to recognize online threats like phishing and malware. By adopting safe habits, you become the first line of defense against data loss, protecting your digital identity in an evolving world.

CYBERCRIME HELPLINE: 1930 • STAY VIGILANT • ENABLE MFA • CHANGE DEFAULT PASSWORDS • ENCRYPT SENSITIVE DATA •

1. Create Strong Passwords

Use at least 12 characters combining uppercase, numbers, and symbols. Experts recommend a [Password Manager](https://www.pcmag.com) for maximum safety.

2. Use Multi-Factor Authentication (MFA)

MFA adds a critical second layer of defense. Even if a password is leaked, hackers cannot access your account without the secondary code.

3. Use Reliable Antivirus Software

Modern antivirus scans for real-time threats and blocks malicious downloads. Keep software updated via [Norton Security](https://us.norton.com).

4. Change Default Passwords

Most IoT devices ship with factory settings like "admin". Always change default credentials immediately to prevent automated attacks.

5. Encrypt Sensitive Data

Encryption scrambles data into unreadable code. It ensures that even if files are intercepted, they remain useless to unauthorized parties.
